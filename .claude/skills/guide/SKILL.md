# 운영자 가이드 작성 스킬

비개발자 운영자가 **복사-붙여넣기만으로** 따라할 수 있는 가이드를 작성한다.
초등학생도 실수 없이 따라할 수 있는 수준이 기준이다.

## 필수 규칙 7가지

1. **한 단계 = 한 동작.** "~하고 ~한 뒤 ~하세요" 금지. 전부 쪼갠다.
   각 단계는 `**N단계.**` 로 번호를 매긴다.
2. **모든 단계에 바로가기 링크 제공.** 메뉴를 찾아가게 하지 말고
   `👉 https://정확한주소` 를 준다. 딥링크가 불확실하면 메인 주소 + 클릭 경로.
3. **입력할 값은 전부 코드블록으로.** 운영자가 타이핑할 일이 없게 한다.
   코드블록의 복사 버튼을 쓰라고 안내한다 (마우스 드래그 복사는 글자가 잘림).
4. **붙여넣는 위치를 반드시 구분.** "브라우저 주소창"인지 "화면 안의 입력칸"인지 명시.
   입력 칸이 여러 개면 어떤 칸에 어떤 값인지 표나 그림으로 짝을 지어준다:
   ```
   ┌─ 이름 * ──────────┐   ← 위쪽 작은 칸 = 변수 이름
   └────────────────────┘
   ┌─ 값 * ────────────┐   ← 아래쪽 큰 칸 = 실제 값
   └────────────────────┘
   ```
5. **각 단계에 성공 확인 방법.** `✔ 성공 확인: ~가 보이면 성공` 형식.
   실패 시 대처도 짧게: `❌ ~가 나오면 → ~부터 다시`.
6. **민감정보(시크릿/토큰/키)는 텍스트로 받기.** 스크린샷은 I/l/1, O/0 판독 불가.
   "스크린샷 말고 글자로 붙여넣어 주세요"를 명시한다. 반대로 화면 상태 확인은 스크린샷이 좋다.
7. **cmd 등 명령어는**: 코드블록 복사 버튼 → 메모장에 먼저 붙여넣기 → 한 줄로 온전한지
   확인(특히 앞뒤 잘림) → 그 다음 cmd에 붙여넣기 순서로 안내한다.

## 가이드 템플릿

```markdown
# 🔧 [무엇을 하는지] ([예상 소요시간])

**1단계.** [한 동작]
👉 https://바로가기주소

**2단계.** [화면 안의 어떤 칸]에 아래 값 붙여넣기:

​```
붙여넣을값
​```

✔ 성공 확인: [이 화면/문구가 보이면 성공]

...

---
완료되면 [무엇]을 알려주세요 → 다음 단계 [무엇]으로 넘어갑니다.
```

## 운영 원칙

- **한 번에 가이드 하나씩.** 완료 확인을 받은 뒤 다음 가이드로 넘어간다.
- **어시스턴트가 확인/처리할 수 있는 것은 절대 운영자에게 시키지 않는다.**
  가이드 전에 자동화 가능한 부분을 먼저 처리하고, 불가능한 부분만 안내한다.
- 실패 보고를 받으면: 원인을 먼저 진단해 설명하고, 고치는 단계만 다시 (처음부터 반복 금지).
- 마지막에는 항상 "완료되면 ~을 알려달라 + 그 다음이 무엇인지"를 붙인다.
